# make_AE_movie テストコード仕様

## 対象と目的

対象コードは [make_AE_movie.test.cjs](make_AE_movie.test.cjs)、検証対象は [make_AE_movie.jsx](../make_AE_movie.jsx)。本書は現在のテストコードが検証する内容をまとめたものである。

Node.js上でAfter EffectsのAPIを模擬し、jsx全体を実行して、プロジェクト生成の制御フローと設定値を確認する。実際のAfter Effects、画像・音声ファイル、`.aep` ファイルは使用しない。

## 実行方法・合否判定

Node.jsが利用できる環境で、リポジトリのルート（`E:\Cicada`）から実行する。

```powershell
node make_AE_movie/tests/make_AE_movie.test.cjs
```

使用するモジュールはNode.js標準の `fs`、`vm`、`assert/strict`、`path`。追加パッケージのインストールは不要。

すべての検証に成功すると、終了コード0で以下を出力する。

```text
PASS: composition, spectrum, image fit, cancellation, failures, logging, filenames
```

検証に失敗するとアサーションエラー等で終了する。テストは最初の失敗で停止するため、それ以降のケースは実行されない。

## テスト環境

`run(options)` ごとに独立した状態を作成し、`vm.runInNewContext` でjsxを実行する。

| 模擬対象 | 動作 |
|---|---|
| `File`・`Folder` | パス、存在判定、素材選択、保存先選択、ログ書き込みをメモリ上で管理 |
| `ImportOptions`・`FootageItem` | 読み込み可否、静止画・音声の属性を模擬 |
| `app.project.close` | 保存確認の指定とキャンセルを検証 |
| `app.newProject`・`save` | 新規作成回数、保存先、保存失敗を記録 |
| コンポジション | 尺をフレーム単位へ丸める処理と、10800秒超の拒否を模擬 |
| レイヤー | 並べ替え、インデックス、尺、トランスフォームの値を保持 |
| エフェクト | `ADBE AudSpect` の識別名を検証し、プロパティ値を保持 |
| Undoグループ | 開始・終了の差が各実行終了時に0であることを確認 |
| `alert` | 通知文言を配列に記録 |

基本入力は画像 `/input/image.png`、音声 `/input/音声 100%.wav`、保存先 `/output`。画像は800×1200、ピクセル縦横比1、音声尺は12.5秒とする。

## 正常系

次の3条件で、保存成功と共通の設定値を検証する。

| 条件 | エフェクトの表示名 | 画像サイズ | ピクセル縦横比 |
|---|---|---|---|
| 基本 | 日本語 | 800×1200 | 1 |
| 横長画像 | 英語 | 2400×800 | 1 |
| 非正方形ピクセル | 日本語 | 800×1200 | 2 |

共通の期待値は以下のとおり。

| 項目 | 期待値 |
|---|---|
| コンポジション | 1920×1080、30 fps |
| ワークエリア尺 | 13秒 |
| レイヤー順序（上から） | `Audio_Source`、`Spectrum`、`Background_Image` |
| 音声レイヤー終端 | 12.5秒 |
| Spectrum・画像レイヤー終端 | 13秒 |
| Spectrumの音声参照 | `Audio_Source` のインデックス |
| 元画像との合成 | 0（無効） |
| 開始・終了周波数 | 300 Hz・1500 Hz |
| 最大高さ・太さ・周波数バンド | 6000・8・128 |
| エフェクトの開始・終了ポイント | `[4, 1076]`・`[1916, 1076]` |
| 内側・外側のカラー | ともに `[1, 1, 1, 1]`（白） |
| Spectrumレイヤーの位置 | `[960, 480]` |
| Spectrumレイヤーの不透明度 | 50 |

画像については、設定されたスケールと素材のピクセル縦横比から計算した表示幅・高さが、1920×1080以上になることを検証する。

## キャンセル

| 条件 | 検証内容 |
|---|---|
| 画像選択をキャンセル | 既存プロジェクトを閉じず、新規作成せず、ログを書かない |
| 音声選択をキャンセル | 同上 |
| 保存先選択をキャンセル | 同上 |
| 既存プロジェクトの保存確認をキャンセル | 新規作成せず、ログに「中止」を記録する |

既存プロジェクトを閉じる際は、保存確認を行う `PROMPT_TO_SAVE_CHANGES` が指定されることも検証する。

## 異常系

以下のケースでは保存されず、通知に「処理結果: 失敗」が含まれることを検証する。また、プロジェクトを閉じる呼び出しが初期の1回だけであり、生成途中のプロジェクトを失敗後に閉じないことを確認する。

| 条件 | 模擬する異常 |
|---|---|
| `invalidImage: true` | 画像が静止画ではない |
| `duration: 0` | 音声尺が0秒 |
| `duration: 10801` | 模擬環境のコンポジション尺上限を超える |
| `effectFailure: true` | Audio Spectrumを追加できない |
| `saveFailure: true` | プロジェクト保存時に例外が発生する |

ログファイルを開けない場合は別に検証する。`.aep` 保存は成功し、通知には「処理結果: 成功」と「ログ出力に失敗」の両方が含まれることを確認する。

## 保存ファイル名

| 音声ファイル名・既存ファイル | 期待する保存先 |
|---|---|
| `CON.wav` | `/output/_CON.aep` |
| `a:b.wav` | `/output/a_b.aep` |
| `song.wav`、既存の `song.aep` と `song_001.aep` | `/output/song_002.aep` |

基本入力には日本語・空白・`%` を含む名前を使用し、正常系の保存まで実行する。ただし、そのケースの保存先文字列自体の一致は現在のコードでは検証していない。

## 秒単位の尺切り上げ

| 音声尺（秒） | コンポジション尺（秒） |
|---|---|
| 267.185555555556 | 268 |
| 0.001 | 1 |
| 12.5 | 13 |
| 12 | 12 |
| 12.00001 | 13 |
| 12.99999 | 13 |
| 10800 | 10800 |

各ケースで保存成功、ワークエリアとコンポジション尺の一致、音声レイヤーの元の尺の維持、画像・Spectrumのコンポジション終端への一致を確認する。コンポジションが音声より短くならず、追加される長さが1秒未満であることも検証する。

さらに、音声尺267.185555555556秒に対して、作成されたコンポジションを要求尺より1フレーム短くする異常を注入する。保存されず、通知に「実際の尺=」を含む診断情報が出ることを確認する。

## 検証範囲の制約

このテストは模擬APIへの呼び出しと設定値を確認する。After Effects実機での動作を保証するものではない。

- 実際の素材の読み込み、音声再生、スペクトラムの描画、保存した `.aep` の再読み込みは実機確認が必要。
- プロパティの表示名・型・値の許容範囲、色や座標の解釈、コンポジション尺の丸めは模擬環境の定義に依存する。
- JSXはNode.jsのJavaScriptエンジンで評価するため、ExtendScript固有の構文互換性は保証しない。
- 実際のファイル権限、UTF-8ログの追記、書き込み・クローズ失敗は検証しない。ログ異常系はファイルを開けないケースのみ。
- 素材不存在、読み込みAPIの例外、不適切な音声素材、エフェクトプロパティの欠落・設定拒否は現在のテストケースに含まれない。
- 画像の中央座標・アンカーポイント、音声有効化、全レイヤーの開始時刻など、jsxが設定するすべての値を個別に検証しているわけではない。

仕様やテストケースを変更した場合は、本書の期待値と検証範囲も併せて更新する。

# makeAEP_simple 仕様・作業指針

## 目的

`../makeAEP/make_AE_gsmovie.jsx` をベースに、CSVを使用せず、ファイル選択とテキスト入力でテンプレートから1件の `.aep` を生成する。
実装は `make_AE_gsmovie_simple.jsx`。After Effects の ExtendScript / ScriptUI を使用する。

## 使用手順

1. After Effects の「ファイル → スクリプト → スクリプトファイルを実行」から本スクリプトを選択する。
2. テンプレート `.aep`、音声素材1点、背景の静止画像1点を順に選択する。
3. ポップアップのテキストボックスに保存ファイル名、`Category_Genre`、`Original_Arrange`、`Title` を入力する。
4. 「生成」を押し、保存先フォルダを選択する。
5. 現在のプロジェクトに未保存の変更がある場合は、After Effects の保存確認に従う。キャンセルした場合は生成を中止する。
6. 生成したプロジェクトを開いた状態で完了し、保存先を表示する。

テキスト3項目は複数行入力に対応する。保存名の初期値は音声ファイル名（拡張子なし）。全項目必須で、空白のみの入力は受け付けない。素材・保存先選択や入力画面でキャンセルした場合、テンプレートを開かずに終了する。

## テンプレート要件

- 対象コンポジション名は `gs_template`。アクティブコンポジションには依存しない。
- `Spectrum` レイヤーに既存の Audio Spectrum エフェクトが必要。
- `Category_Genre`、`Original_Arrange`、`Title` の同名テキストレイヤーが必要。
- 対象コンポジション・対象レイヤー名はそれぞれ一意にする。
- `Background_Image` / `Audio_Source` はスクリプトが追加するため、テンプレートには置かない。既存の場合はエラーとする。
- Source Text の式は無効にする。式が有効な場合は入力値が上書きされるためエラーとする。
- 各既存レイヤーの inPoint は音声の終了時刻より前にする。

## 生成仕様

- 1回の実行につき、毎回テンプレートを開いて1件生成する。CSV読み込み・一括生成は実装しない。
- 素材の拡張子は限定せず、存在とフッテージとしての読み込み可否を確認する。画像は静止画、音声は音声トラックと正の尺が必要。
- 背景は `Background_Image` として `Spectrum` の直下に追加し、縦横比を保ってコンポジション全体を覆うように拡大・中央配置する。
- 音声は `Audio_Source` として `Spectrum` の直上に追加する。映像付き素材の映像は無効にする。
- 追加レイヤーの startTime / inPoint は0、outPointは音声尺とする。
- コンポジションの duration、ワークエリア、全レイヤーの outPoint を音声尺に合わせる。既存レイヤーの開始位置やキーフレーム時刻は変更しない。
- テキストは同名レイヤーの Source Text に反映する。既存 TextDocument の文字列を更新し、テンプレートの位置・書式・テキストアニメーターを利用する。Source Text にキーがある場合は各キーの文字列を更新する。
- Audio Spectrum は既存エフェクトの Audio Layer のみ更新する。名前による検索に加え、LAYER_INDEX 型による検索を使用する。
- ロックされたレイヤーの更新時は一時解除し、元のロック状態に戻す。

## 保存・エラー処理

- 保存形式は `.aep`。テンプレート自体は上書きしない。
- 保存名末尾の `.aep` は除去してから付与する。禁止文字・制御文字を `_` に置換し、末尾の空白とピリオドを除去する。Windows予約名には `_` を前置する。
- 同名のファイル・フォルダがある場合は `_001`、`_002` と連番を付ける。
- 保存先の `process_log.txt` にUTF-8で開始・終了日時、入力パス、出力名、結果、保存先またはエラー理由を追記する。
- ログ出力失敗は `.aep` の生成結果とは別に通知する。
- 生成処理で例外が発生した場合はエラーを表示し、その時点のプロジェクトを確認用に開いたままにする。自動的に破棄・上書き保存しない。
- 素材は外部ファイルを参照する。素材のコピー・収集はしない。

## 対象外・実装方針

- 動画書き出し、レンダーキュー・Media Encoderへの登録は行わない。
- エフェクトの新規作成・見た目の変更、プロジェクトパネル内の整理は行わない。
- 既存のCSV版は変更しない。
- ExtendScriptで動く旧来のJavaScript構文を使い、ユーザー向け表示は日本語とする。

## 動作確認

- 正常系：画像・音声・3項目を入力し、保存した `.aep` を再度開いて画像配置・音声再生・スペクトラム・文字・尺を確認する。
- 複数行の日本語、Source Text のキー、ロックされたレイヤーを確認する。
- 入力キャンセル、未保存プロジェクトの保存確認キャンセルで生成しないことを確認する。
- 同名出力が連番になり、テンプレートを上書きしないことを確認する。
- 必須レイヤーなし、不正素材、音声より後に開始するレイヤー、保存失敗時のエラー表示を確認する。
- JavaScriptの構文検査だけでは、After Effects固有API・描画・ScriptUIの実動作は保証できないため、実機確認を行う。
